# Animated Website

A beautiful, fully animated website with smooth transitions, floating shapes, and interactive elements.

## Features

✨ **Smooth Animations**
- Slide-in animations for title and subtitle
- Floating background shapes
- Button hover effects and pulse animation
- Beautiful gradient background

🎨 **Modern Design**
- Responsive layout
- Clean and professional UI
- Purple gradient theme
- Smooth transitions and effects

🖱️ **Interactive Elements**
- Clickable button with animation feedback
- Hover effects on buttons
- Dynamic color changes

## How to Use

1. Clone the repository
2. Open `index.html` in your web browser
3. Enjoy the animations!

## File Structure

```
new-repository-seo3/
├── index.html    (Main HTML file with animations)
└── README.md     (This file)
```

## Browser Support

Works on all modern browsers that support CSS3 animations and JavaScript.
